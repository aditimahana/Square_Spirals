# Square Spirals

A collection of Python Turtle exercises exploring geometric patterns through loops, angles and movement. This project contains two variations of an expanding square spiral.

## Files

| File | Description |
|---|---|
| `SquareSpiral1.py` | Draws an expanding square spiral, increasing the movement distance by 1 with each iteration. |
| `SquareSpiral2.py` | Draws a faster-growing square spiral by increasing the movement distance by 2 with each iteration. |

## Concepts Learned
- Importing and using the `turtle` module
- Creating and controlling a Turtle pen
- Using `for` loops and `range()`
- Understanding angles and geometric patterns
- Experimenting with movement distances and parameters

## How to Run
1. Make sure Python is installed.
2. Run either `SquareSpiral1.py` or `SquareSpiral2.py`.
3. Watch the turtle draw the spiral!

## Key Differences
- **Square Spiral 1:** Uses `t.forward(x)`.
- **Square Spiral 2:** Uses `t.forward(2*x)`.

Both programs use a 90-degree turn to create square spirals, but produce different patterns due to the change in movement distance.
